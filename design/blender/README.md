# 空序 · 示范园区模型

本轮资产用于UI设计与场景展示。园区为600×420米的概念场地，尚未绑定真实地理坐标或运行数据。

## 打开与使用

- 在 Blender 中直接打开[空序-示范园区-v1.blend](D:/挑战杯项目/城市低空多机协同调度与航路规划决策平台/design/blender/空序-示范园区-v1.blend)。工程已在 Blender 5.2.2 中重新打开检查，包含独立园区场景及编辑视角，无需运行脚本。
- [airorder-campus-v1.glb](D:/挑战杯项目/城市低空多机协同调度与航路规划决策平台/design/models/airorder-campus-v1.glb)用于后续网页展示，包含静态园区，大小3,439,212字节（约3.44 MB）。航路、示例飞机、摄影机与灯光未包含在其中。
- [园区总览](D:/挑战杯项目/城市低空多机协同调度与航路规划决策平台/design/空序-园区总览-v2.png)为2048×1536透明背景PNG；[设施近景](D:/挑战杯项目/城市低空多机协同调度与航路规划决策平台/design/空序-园区近景-v2.png)为1920×1280透明背景PNG。
- [首页概念草图 V2](D:/挑战杯项目/城市低空多机协同调度与航路规划决策平台/design/空序-首页概念草图-v2.png)将总览渲染与静态UI组合，尺寸1920×1080。

Blender场景采用米制，1单位为1米，Z轴朝上。GLB按glTF标准转换为Y轴朝上。场地使用局部坐标，原点位于园区中央附近。

## 集合组织

| 集合 | 内容 |
| --- | --- |
| 01 场地与道路 / Site | 场地基座、道路、步行与作业铺装、道路标线 |
| 02 建筑 / Buildings | 仓储、研发办公、应急服务、飞行服务与运控设施，共10组建筑体量 |
| 03 景观 / Landscape | 114株树木、水景、步桥与公共空间设施 |
| 04 起降与园区设施 / Facilities | 4处起降位、停车与装卸设施、车辆等 |
| 05 航路样例 / Airspace sample | 配送、巡检、应急示意曲线和飞机模型，可整组隐藏 |
| 90 摄影与照明 / Presentation | 总览、近景、总平面摄影机及场景灯光 |

建筑按用途组织为可选对象；重复树木和设施复用网格。网页导出保留结构几何，省略细小倒角修改器；当前GLB包含136个节点、25个网格、26个材质，仅有一个园区场景。文件体积与结构已检查，浏览器实际帧率需在实现阶段测量。

## 编辑与渲染

默认打开材质预览与正交视角。可在右上集合列表中隐藏航路样例，单独查看园区；也可切换三个摄影机观察总览、运控设施近景或总平面。渲染采用Cycles；当前工程保存为CPU渲染、32采样与降噪，两张交付图已检查。

[build_airorder_campus.py](D:/挑战杯项目/城市低空多机协同调度与航路规划决策平台/design/blender/build_airorder_campus.py)为建模生成脚本，用于追溯和重新生成初始资产。运行会重新生成场景及输出文件，日常调整直接编辑已保存工程即可。`open_airorder_view.py`用于将单场景资产整理为带工作区的工程，无需重复执行。

示例航路只用于表达空间设计，没有经过飞行可行性、空域规则或安全间隔验证。当前交付为设计与模型资产，尚未编写应用功能。
