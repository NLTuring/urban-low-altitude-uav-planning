# 空序 AIRORDER · 浏览器交互原型

本原型将现有Blender园区资产用于可操作的三维态势界面，串联“发现冲突 → 比较方案 → 协调确认 → 外部落实回执 → 运行观测 → 审计记录”。视觉沿用石墨底色、暖灰建筑、克制的航路色与普通工具栏。

## 打开

本机预览地址：[http://127.0.0.1:4173](http://127.0.0.1:4173)。已启动时直接访问即可。

下次可双击[启动原型.cmd](D:/挑战杯项目/城市低空多机协同调度与航路规划决策平台/prototype/启动原型.cmd)，脚本会复用当前空序服务，或启动本地构建预览并打开浏览器。服务仅监听本机回环地址。

首次在其他电脑使用，在本目录运行：

```powershell
npm ci
npm run build
node scripts/start.mjs
```

开发时运行 `npm run dev`，使用同一地址。关闭开发终端可停止该开发服务；启动脚本建立的后台服务可通过任务管理器关闭对应Vite进程。

## 建议体验顺序

1. 拖动旋转园区、滚轮缩放、右键平移；点选D03、P02或E01航路标签查看任务。
2. 点击业务图例过滤航路，拖动高度尺改变可见高度范围，切换三维/平面视图。
3. 拖动时间带或播放预演，观察三架示例飞机的位置变化。
4. 点击“预计时空接近”事件，进入C-017，选择“比较调整方案”。
5. 比较错峰45秒和东侧绕行，观察原计划参考线、调整后的航迹和飞行时序。抬升高度的样例方案因起降时窗重叠而不可采用。
6. 发送协调建议（演示），在“演示控制”中分别模拟两家运营人确认，再模拟落实回执及运行观测。也可尝试拒绝、超时或计划变更。
7. 在“审计”查看版本与步骤记录，可下载JSON。刷新页面会重置演示。

查询栏支持任务编号、运营人、业务关键词及“未来的冲突”“比较方案”等预设表达。`Ctrl K`聚焦检索，`Esc`关闭检索或对话框。设置中提供轻量渲染和重置整个演示。

## 当前范围

| 已提供 | 说明 |
| --- | --- |
| 可操作三维园区 | 加载约3.44 MB GLB，旋转、缩放、平移、平面切换、自动冲突聚焦 |
| 航路与任务 | 三条独立航路、直接点选、详情面板、业务过滤、标签避让 |
| 高度与时间 | 航迹高度裁切、飞机按预设时序插值、当前/预演/样例回放 |
| 方案比较 | 两个可选预设方案与一个不可用方案，原计划和预演分离 |
| 协调状态 | 版本绑定、逐方确认、拒绝、撤回、超时、计划失效、逐方落实回执、观测归档 |
| 过程记录 | 当前页面内的演示日志，JSON导出 |
| 浏览器容错 | 模型加载失败时展示静态总览，保留业务操作；可切换轻量渲染 |

轨迹、冲突、候选代价与回执均为作者设定的样例。冲突界面中的30米阈值用于说明流程。真实运行数据、运营人接口、优化算法、审批流程、账户权限和语言模型尚未接入；自然语言入口当前执行本地样例检索。协调按钮仅改变本页演示状态，不向外部系统发送信息。

高度控制当前只裁切航路和飞机，建筑维持完整体量。历史回放使用同一组样例轨迹。网页模型的尺度使用米制局部坐标，未绑定实际地理信息。

## 项目结构

| 文件 | 职责 |
| --- | --- |
| `src/App.tsx` | 工作台界面、时间控制、方案面板与查询入口 |
| `src/Campus.tsx` | Three.js场景、GLB加载、轨迹与标签、相机交互 |
| `src/domain.ts` | 样例数据、轨迹插值、协调状态与查询规则 |
| `src/styles.css` | 视觉样式与办公屏幕适配 |
| `public/models/campus.glb` | Blender导出的静态园区副本 |
| `src/domain.test.ts` | 协调与空间时间规则测试 |
| `e2e/prototype.spec.ts` | 浏览器操作、闭环与异常流程测试 |

技术栈：React、TypeScript、Vite、Three.js、Lucide。依赖版本保存在 `package-lock.json`。原始Blender工程仍位于 `design/blender`，本轮未修改原始模型。

## 验证

```powershell
npm run build
npm run test:coverage
npm run test:e2e
```

验证覆盖协调规则、时间/高度、查询、拒绝后重新发起、浏览器渲染与常见办公分辨率。业务规则模块的覆盖率单独统计，不能等同于整个应用的测试覆盖率。E2E默认使用本机Google Chrome。

2026年10月4日本机验证结果：生产构建成功；11项规则测试与5项浏览器流程测试通过；`domain.ts`的语句、分支、函数与行覆盖率均为100%。已检查1600×1000与1366×768布局。模型加载失败、三维旋转与缩放、航路点选及轻量渲染均有浏览器用例。
