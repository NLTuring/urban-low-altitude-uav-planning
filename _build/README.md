# 文档生成说明

本目录是两份文档的生成源码。修改内容后，可一键重新生成 Word 文档与预览 PDF。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `docgen.py` | 排版引擎：宋体字体、标题层级、表格、提示框、目录域、页眉页脚等基础模块 |
| `content_a.py` | 项目简介正文 第一部分：前言 ~ 第六章（背景、方案、技术、市场、商业模式） |
| `content_b.py` | 项目简介正文 第二部分：第七章 ~ 附录（团队、风险、规划、BP 指南、PPT 指南） |
| `bp_content.py` | 商业计划书样板正文：使用说明、设计纲要、一 ~ 十章、定稿自检 |
| `fontfix.py` | 保存后归一化字体：清除模板残留的主题字体与 Courier，确保全文有效字体为宋体 |
| `make.py` | 构建项目简介（两遍编译：第一遍取页码，第二遍写入目录） |
| `make_bp.py` | 构建商业计划书样板（同样两遍编译） |
| `extract_toc.py` | 从渲染出的 PDF 中提取各级标题的真实页码 |
| `check.py` | 结构自检：字体统计、表格数、域代码、节与页码设置、连续空段 |
| `verify.py` | 字体自检：确认文档中所有字体引用均为宋体 |
| `check_caption_orphans.py` | 版式自检：检测“表格标题孤立在页底、表格翻到下一页”的缺陷 |
| `render.py` | 将 PDF 逐页导出为 PNG，便于排版检查 |
| `toc.json` / `toc_bp.json` | 上一次构建时提取到的标题页码 |
| `pdf/`、`png/`、`png_bp/` | 构建过程中生成的 PDF 与逐页 PNG |

## 重新生成文档

```bash
cd _build
python make.py       # 重新生成 项目简介与BP-PPT编制指南
python make_bp.py    # 重新生成 商业计划书样板
```

脚本会自动完成：生成 docx → 归一化字体 → 调用 LibreOffice 转 PDF → 提取页码 → 重新生成带完整目录的 docx → 再次转 PDF 校验。

**如果生成的 docx 正在 WPS 或 Word 中打开**，脚本会自动改存为 `……(新版本).docx` 并给出提示。想覆盖原文件，请先关闭文档再运行。

## 修改内容

- 改文字、表格、章节：编辑 `content_a.py` / `content_b.py`（项目简介）或 `bp_content.py`（商业计划书样板）。内容以 `('类型', 内容)` 的形式按顺序排列。
- 支持的内容类型：`h1` 一级标题、`h2` 二级标题、`h3` 三级标题、`p` 正文段落、`b1`/`b2` 项目符号、`note` 提示框（内容为 `(标签, 正文)` 二元组）、`fig` 图示占位说明、`tbl` 表格、`cap` 表格标题、`pb` 分页。
- 改字体、行距、页边距、封面样式：编辑 `docgen.py`。

## 注意

- 表格内容（`tbl`）中每一行的列表元素个数必须与 `cols` 的列数一致；少一个闭合符号会导致文档无法生成。
- 文档正文要求使用宋体，`docgen.py` 中的 `FONT = '宋体'` 控制全局字体，不建议改动。
- 表格标题（`cap`）与表格（`tbl`）必须相邻且顺序正确，排版引擎依赖 `keepNext` 链把标题与表头固定在同一页；如新增表格，请保持这一写法。
- `w:pPr` / `w:trPr` 的子元素必须按 OOXML 规定顺序插入，直接 `append` 会被渲染器静默忽略（这正是此前“表格标题孤立页底”的根因）。如需新增此类属性，请复用 `docgen.py` 中 `keep_with_next`、`_trpr_set`、`para_mark_size` 的写法。
- 目录行高使用固定值（`line_exact`），避免中文字体度量差异导致目录溢出到第二页。
- 目录是「预填内容 + 可更新域」的组合：打开文档即可看到完整目录与页码，在 Word 中右键「更新域」可按 Word 自身排版重算页码。
- 定稿前建议依次运行 `python verify.py <docx>`、`python check.py <docx>`、`python check_caption_orphans.py <pdf>` 三项自检。
